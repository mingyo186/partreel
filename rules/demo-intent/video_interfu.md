### 2-1. 버스 커넥터 → 브리지 → 메인 FPGA: "세로 한 줄"

- BUS1(158.12, 158.75, 바닥 탭) → **U11 S5933 (141.60, 129.44)** → **U24 XC4005 (141.60, 88.17)**.
- **U11과 U24의 x가 소수점까지 동일(141.60)**, 회전도 둘 다 90°.
  → PCI AD 버스는 커넥터에서 위로 곧게, 애드온 버스는 다시 위로 곧게 간다.
- 공유 신호넷 수 실측: BUS1↔U11 **51넷**, U11↔U24 **47넷**, U23↔U24 **47넷**.
  즉 결선이 가장 많은 3개가 서로 최근접 배치되었다.
- 결과 배선 길이(넷 바운딩박스 span, 맨해튼):
  - `P_AD*` 32넷: 중앙값 **20.3mm**, 최대 37.0 — PCI 32비트 버스가 20mm 안에 끝난다.
  - `IA*` 10넷: 중앙값 7.3mm.
- U23(103.50, 86.87)은 U24와 y가 1.3mm 차이로 사실상 같은 행. U11-U24-U23이
  ㄱ자로 붙고 **U24가 가운데(허브)**. U24는 U11(47넷)·U23(47넷)·SIMM 8장(각 18넷)
  모두와 물리므로 가운데가 최적. [근거: 결선수-거리 실측]

### 2-2. SIMM 8장 — 열 정렬의 교과서

- U12~U19 전부 **x = 234.31로 동일**, 회전 0°, y = 64.14 / 73.03 / 81.92 / 90.81 /
  99.69 / 108.58 / 117.47 / 126.36 → **피치 8.89mm(0.35") 정확히 일정**.
- 8장 서로 각각 **48개 신호넷 공유**(A0~A10, RAS/CAS, R/W, DQ0~31 = 완전 공유 버스).
- `TVRAM*` 32넷 span: 중앙값 **186.1mm, 최대 191.7mm** → 32비트 폭 전체의 길이
  편차가 **5.6mm**뿐. 소자를 한 줄로 세워 버스를 나란히 끌면 길이가 저절로 맞는다.
  등장배선을 따로 하지 않고 **배치로 등장을 만든 것**.
- 데이터 32비트를 받는 U22(304.93, 74.42)는 SIMM 배열 **오른쪽 끝 바로 옆**,
  주소/제어를 주는 U24는 **왼쪽**. 즉 SIMM 열이 두 컨트롤러 사이의 다리다.
- SIMM 8장에 100nF이 하나도 없다 — **SIMM 모듈 자체가 온보드 디커플링을 갖기 때문**
  (72핀 SIMM 표준). "IC당 1개" 규칙의 정당한 예외.

### 2-3. 74LS245 4개 — 뒷면 세로 3연

- U3(168.78, 106.55) / U4(168.78, 91.57) / U5(168.78, 121.03): **x 동일, 회전 0°,
  전부 뒷면(B.Cu)**. U6만 (197.74, 138.81) 앞면.
- 위치는 U24(x=141.6)와 SIMM 왼쪽 끝(x=176.3) **사이의 좁은 틈**. 앞면은 이미
  꽉 차서 뒷면으로 내려 보냈다. [추정 — 앞면 점유 상황이 근거]
- 각 245는 U24/U22/SIMM에 8~10넷씩 균등하게 물린다(바이트 레인 분할).

### 2-4. 비디오 코덱 블록 — 오른쪽 3분의 1

- U10 BT812(335.41, 76.33) 디코더 / U8 BT253(311.28, 112.65) A/D / U9 BT473(343.54, 114.94) RAMDAC.
- 서로 공유넷: U8↔U9 36, U10↔U9 35, U10↔U8 34 → 3개가 삼각형으로 32~44mm 안에 뭉침.
- 아날로그 기준·크리스털은 각 IC 옆: X2 30MHz(357.63, 91.95)는 U10에서 26.9mm,
  로드캡 C65/C66은 X2에서 **6.3mm** 이내.
- BT812의 아날로그 전원 VAF는 **별도 넷** (`/pal-ntsc.sch/VAF`, 24핀) — L4 22uH로
  +5V에서 분리 급전. BT253/BT473의 VAA도 별도 넷 + L5 22uH. **아날로그 전원을
  인덕터로 분리하고 그 넷 전용 디커플링을 붙였다.**

### 2-5. 커넥터-로직 흐름 방향: 이 보드의 유일한 큰 타협

- 입력: P3/P1/P2 BNC(x=59.05) = BLUE/RED/GREEN_IN → 커넥터 바로 옆에 **75Ω 종단
  R45/R46/R47(x=66.5~67.9)** → 그다음 보드를 가로질러 x=294~339의 220Ω 직렬
  R22/R23/R24 → U8 BT253.
- 출력: U9 BT473(x=343.5) → 보드를 가로질러 → J4 DB9(70.74, 144.15) 바로 옆의
  **75Ω 종단 R42/R43/R44(x=75.06)**.
- 실측 span: `/GREEN_IN` **355.8mm**, `/RED_IN` 351.7, `/RED_OUT` 328.5 — 보드
  전장에 맞먹는다. 366개 신호넷 중 최장 5개가 전부 이 아날로그 RGB다.
- **왜 이렇게 했나**: 브래킷은 왼쪽 끝에 고정(기구 제약), 비디오 코덱 3종은
  서로 34~36넷씩 물려 있어 떼어놓을 수 없다. 둘 중 하나를 포기해야 했고
  **"디지털 다중결선 클러스터 유지"를 택하고 "아날로그 단일선 길이"를 버렸다.**
  단일선 3~5개는 길어도 임피던스만 맞추면 되고, 32비트 버스를 늘리면 8배 손해다.
  [추정 — 설계자 의도 기록은 없음. 기하와 넷 수가 근거]
- 대신 **종단 저항은 양쪽 다 커넥터 발치에** 두었다(입력 75Ω, 출력 75Ω 대지).
  긴 선을 감수하되 종단 위치는 원칙대로.
- 마지막 아날로그 단인 TDA8501 인코더 블록(x 67.9~84.5)은 **출력 커넥터 옆**.
  RGB_OUT이 J4로 가면서 C58~C60 47nF으로 U20에도 분기 → CVBS/Y/C가 P8·J4로
  나간다. **"최종 아날로그 드라이버는 커넥터 쪽"** 원칙은 지켰다.

### 2-6. 디커플링 — 뒷면, IC 몸통 바로 밑

**43개 소형 캡이 전부 `oppSide`** (IC는 앞면, 캡은 뒷면, 캡 중심이 IC
바운딩박스 안). 스루홀/양면 시대의 표준 수법이다.

| IC              | 전원핀 수                | 몸통 밑 캡                      |
|-----------------|--------------------------|---------------------------------|
| U11 S5933       | +5V 8핀                  | C24~C31 = **정확히 8개** + C38 4.7uF 벌크 |
| U10 BT812       | +5V 7핀 + VAF 24핀       | 100nF 11개 (C2,C6,C7,C9~C16)     |
| U24 XC4005-160  | +5V 11핀                 | 100nF 5~6개 + C56 4.7uF          |
| U23 XC4003-100  | +5V 8핀                  | C70~C73 = 4개                    |
| U9 BT473        | VAA 6핀                  | C33/C34/C32 + C42 2.2uF + C51 22uF |
| U8 BT253        | VAA 4핀                  | C36 100nF + C37 100pF + C52 22uF |

- 캡 중심 → 같은 넷 최근접 IC 패드 거리: n=26, p25 **3.44mm**, p50 **5.05mm**,
  p75 5.86, 최대 30.2(C67은 커넥터 벌크라 예외).
  ※ 이 수치는 "몸통 밑 배치"라서 커 보인다. 28mm QFP 중앙 밑에 붙이면 최근접
  전원핀까지 5mm가 나오는 게 정상 — 실제 루프는 캡→비아→전원플레인이라 짧다.
- 벌크는 전원 인입부에: C67 4.7uF(99.44, 149.73), C68/C69 4.7uF(+3.3V, y=148.46)
  가 PCI 커넥터(y=158.75) 바로 위.

| 비아               | 0.889/0.4 807개 (단일 규격)                                    |

| bottom 방향        | 수직 11% / **수평 76%** / 45° 13%                              |
| In1(GND) 배선량    | **639mm** (거의 통짜 플레인 유지)                              |
| In2(+5V) 배선량    | **2713mm** (오버플로 신호를 여기로 뺌, 수평 69%)               |

→ **전원을 플레인으로 빼면 배선 폭이 하나로 통일된다.** 전원 배선폭 규칙이
아예 필요 없어진다.
→ **플레인 두 장 중 희생 순서가 명확하다: GND는 지키고 전원 플레인을 자른다.**

## 3. interf_u — 기능블록별 배치 의도

보드 x 79.38~194.94 / y 34.29~142.49. ISA 탭이 아래(y=133~142), 브래킷이 오른쪽.

### 3-1. "버스 커넥터 바로 위 한 줄" — 가장 선명한 관례

- U2 74LS688(95.89) / U3 74LS541(123.83) / U1 74LS245(151.76) — **셋 다 y=124.46,
  회전 90°로 동일**, x 간격 **27.94mm / 27.93mm = 1.1인치 정확히**.
- 바로 아래가 BUS1 ISA 엣지(y=138.43, 몸통 상단 y≈133.8) → **IC 행과 커넥터
  간극 약 5.6mm**.
- 세 IC의 BUS1 공유넷: U2 9, U1 8, U3 7 → **ISA에 직접 물리는 것만 이 행에 세웠다.**
- 한 행 위(y≈113)는 2차 로직: U8 EP600(123.83, 112.90)은 **U3와 x가 동일**,
  RR1 9×1K(95.89, 113.03)는 **U2와 x가 동일**. → 열도 맞춰 세웠다.
- `REF4`~`REF11` 8넷의 span이 **전부 정확히 19.0mm** — JP1(주소점퍼)·RR1(풀업)·
  U2(비교기)가 정렬돼 있어 8비트가 같은 길이로 간다.

**블록 요약(아래→위)**

| 행         | y      | 내용                                                      | 의미                  |
|------------|--------|-----------------------------------------------------------|-----------------------|
| 0          | 138.4  | BUS1 ISA 골드핑거 (바닥 탭)                                | 시스템 버스           |
| 1          | 124.5  | U2 74LS688 · U3 74LS541 · U1 74LS245 (1.1" 등간격)         | 버스 인터페이스       |
| 2          | 105~113| RR1 풀업 · JP1 주소점퍼 · U8 EP600 · C5/C6 벌크            | 디코드/설정           |
| 3          | 76~93  | U5 628128 SRAM · X1 8MHz군 · U9 XC4003A PGA120             | 코어 (메모리+FPGA)    |
| 오른쪽변   | x=182  | P1 DB25 (브래킷)                                           | 외부 I/O              |
| 위쪽       | 38~42  | D1/D2 LED + R4/R5                                          | 상태 표시             |

### 3-2. 커넥터 → 로직 흐름: 두 커넥터가 양 끝을 잡는다

- **아래(BUS1) = 시스템측**, **오른쪽(P1 DB25) = 사용자측**.
- P1↔U9 **17넷**, 거리 26.0mm → **DB25가 FPGA 바로 옆**. 외부 I/O를 FPGA가
  직접 받는다(버퍼 없음).
- BUS1↔U9 12넷 / U9는 U1·U2·U3 각각과 6~8넷 → FPGA가 두 커넥터 사이 중앙 우측.
- **약점**: U5 SRAM↔U9 FPGA가 **28넷인데 중심 거리 71.4mm**로 이 보드에서 결선이
  가장 많은 쌍이 가장 멀다. `MA*` 17넷 span 중앙값 57.1mm.
  왼쪽 위가 SRAM에 남은 유일한 자리였다(오른쪽=DB25+FPGA, 아래=버스행). 
  **[반례] 커넥터 기구 제약과 큰 패키지 때문에 "결선 많은 쌍은 붙인다" 규칙이
  깨진 사례** — 우선순위가 기구 > 결선임을 보여준다.
- 발진자도 마찬가지: X1 8MHz(113.67, 92.71)의 인버터는 U9 내부(A3핀)인데
  X1↔U9 거리 **45.6mm**. 다만 X1·C2·C3·R1·R2끼리는 3.8~14.0mm로 뭉쳐 있다.
  → **발진 부품끼리 뭉치는 규칙은 지키고, 그 뭉치를 IC에 붙이는 규칙은 놓쳤다.**
  (video의 X1↔U23은 15.9mm, X2↔U10은 26.9mm로 훨씬 낫다.)

### 3-3. 디커플링 — 이 보드의 명백한 결함/시대 한계

- 세라믹 100nF이 **0개**. 47uF 전해 4개(C1/C4/C5/C6)가 전부.
- 그 4개가 IC 밭의 네 구석에 흩어져 있다: C5(87.0,113.0)↔U2, C6(159.4,111.8)↔U1,
  C1(83.2,83.8)↔U5, C4(170.7,52.2)↔U9. 최근접 전원패드까지 9.2 / 9.7 / 17.7 / 23.2mm.
- U3 74LS541, U8 EP600, U9 PGA120에는 20mm 안에 아무 캡도 없다.
- **해석**: 데모 단순화이거나 LS-TTL 시대의 "패키지 2~3개당 1개" 관례로 보인다.
  어느 쪽이든 **현대 기준으로는 따라 하면 안 되는 부분**. [추정]
- 반대로 video는 같은 저자 계열 보드인데 IC당 전원핀 수만큼 붙였다 → 층 수와
  플레인 유무가 디커플링 밀도를 바꾼 것으로 보인다. [추정]

### 3-4. 층 구성과 배선 방향 — 2층의 직교 규율

| 항목            | 실측                                                   |
|-----------------|--------------------------------------------------------|
| 층              | 2층, **바닥에만 GND 존** (앞면 존 없음)                |
| 배선 폭         | 0.432mm 552개 / 0.559mm 151개 (+0.4·0.381·0.3 소수)    |
| 넷클래스        | Default 0.4 / Power 0.5, 비아 1.4-0.6 / 1.6-0.6        |
| 실측 비아       | 1.397/0.6 73개, 1.524/0.6 7개                          |
| **top 방향**    | **수직 81%** / 수평 3% / 45° 16%                       |
| **bottom 방향** | 수평 **85%** / 수직 5% / 45° 10%                       |
| 배선량          | top 2160mm, bottom 2941mm                              |

→ **2층 수배선의 직교 규율이 거의 순수하게 지켜졌다** (top 수직 81%, bottom 수평 85%).
video(4층)도 top 수직 66% / bottom 수평 76%로 같은 규율. **45°는 10~16%로 "꺾는

→ 신호 0.432mm(17mil) / 전원 0.559mm(22mil)로 **폭이 두 가지**. 플레인이 없으니
전원을 배선으로 끌어야 하고, 그래서 전원 폭 규칙이 필요했다.

## 5. 일반화 규칙 후보 (D 시리즈 — 아직 후보, 적용은 승인 후)

기존 규칙집과 번호 충돌을 피하려고 **D**(demo-intent) 접두를 쓴다. 확정되면
`pcb-layout.md`의 P 시리즈로 승격/병합.

### D1. 계층 시트 = PCB 영역 [배치] — 근거: video 8시트 중 6시트가 밀집 클러스터
회로도 시트(기능 블록) 하나는 PCB에서도 한 덩어리로 모은다. video에서
pal-ntsc(x 310~358), RAMS(x=234.31 단일 열), graphic(x 82~157)은 시트 경계가
곧 PCB 경계였다. 시트가 흩어진 경우(ESVIDEO-RVB, muxdata)는 **역할이 둘로
쪼개지는 부품**(출력 종단 저항 → 커넥터 쪽) 때문이었다 → D6과 함께 봐야 함.

### D2. 같은 버스를 공유하는 IC는 한 줄로, 같은 회전으로, 등간격 [배치]
- 근거: SIMM 8장 x=234.31 동일·회전 0°·피치 8.89mm 정확 일정;
  interf_u U1/U2/U3 y=124.46 동일·회전 90°·피치 27.94mm(1.1") 정확;
  video U3/U4/U5 x=168.78 동일.
- **효과가 측정된다**: `TVRAM*` 32넷 길이 편차 5.6mm/186mm, `REF*` 8넷 전부 19.0mm.
  **등장배선(length matching)을 하지 않고 배치만으로 등장을 얻는다.**
- 피치는 인치 격자에 맞춘다(1.1" DIP, 0.35" SIMM).

### D3. 결선 수가 많은 쌍일수록 가깝게, 최다 결선 IC를 가운데 [배치]
- 근거: video BUS1↔U11 51넷/33.6mm, U11↔U24 47넷/41.3mm, U23↔U24 47넷/38.1mm,
  U8↔U9 36넷/32.3mm. U24는 3방향 최다 결선이라 가운데.
- 우선순위: **기구 제약(커넥터 위치·패키지 크기) > 결선 수**. interf_u U5↔U9가
  28넷인데 71.4mm인 것이 그 증거 — 지킬 수 없을 때 무엇을 버렸는지 기록할 것.

### D4. 버스 컨트롤러/브리지는 그 버스 커넥터에 최대한 붙인다 [배치]
- 근거: video U11 S5933이 PCI 커넥터에서 33.6mm → `P_AD*` 32넷 중앙값 20.3mm.
  interf_u 74LS 3종이 ISA 탭에서 5.6mm 간극.
- 반대 방향도 성립: **커넥터에 직접 물리지 않는 IC는 그 행에 끼워 넣지 않는다.**

### D5. 디커플링은 IC당 전원핀 수만큼, IC 몸통 바로 밑 반대면 [배치]
- 근거: video U11 +5V 8핀 ↔ C24~C31 정확히 8개, 전부 뒷면·몸통 바운딩박스 안.
  43개 소형 캡 전원 `oppSide`.
- 양면 실장이 가능하면 **캡을 IC 아래 반대면**에 두는 게 가장 짧다(2D 거리는
  3~6mm로 보이지만 실제 루프는 캡→비아→플레인).
- **예외 1**: 자체 디커플링을 가진 모듈(SIMM, DIMM, DC-DC 모듈)은 붙이지 않는다.
- **예외 2**: 벌크는 IC가 아니라 **전원 인입 커넥터 발치**(video C67~C69).

### D6. 종단·정합 소자는 커넥터 발치, 그 외 수동은 IC 옆 [배치]
- 근거: video 입력 75Ω R45~R47이 BNC에서 7.5~9mm, 출력 75Ω R42~R44이 DB9 옆.
  두 방향 모두 커넥터 쪽. 신호 자체는 280mm를 가로질러도 종단만은 커넥터에.
- **한 시트의 부품이라도 "종단"은 커넥터로, "구동/논리"는 IC로 갈라진다** (D1 예외).

### D7. 풀업 어레이는 잔여 공간으로 밀어도 된다 [배치] — 우선순위 낮음
- 근거: video RR1~RR6이 U11에 각각 8넷씩 물리지만 거리 47~57mm, 커넥터와 IC
  사이 자투리 띠(y 127~143)에 좌우로 분산 배치.
- DC 전용(풀업/풀다운)은 길이 민감도가 없다 → **면적 경쟁에서 먼저 양보시키는
  부품군**으로 분류. 반대로 종단(D6)·디커플링(D5)은 절대 양보 금지.

### D8. 발진 회로는 3~4부품 뭉치로, 뭉치째 IC 옆 [배치]
- 근거: video X2+C65/C66이 6.3mm 이내, X2↔U10 26.9mm; X1군 3.8~14mm, X1↔U23 15.9mm;
  X3+CV1 ~9mm.
- **[반례] interf_u X1↔U9 45.6mm** — 뭉치는 만들었으나 IC에 못 붙였다.
  규칙은 "뭉친다 + 붙인다" 둘 다여야 한다.

### D9. 배선 방향은 층마다 하나로 고정, 45°는 꺾임 전용 [배선]
- 근거(길이 가중 실측): interf_u top 수직 81% / bottom 수평 85%;
  video top 수직 66% / bottom 수평 76%. 45°는 두 보드 모두 10~16%,
  기타 각도 0~2%.
- 2층·4층 모두 같은 규율. **층 쌍(top/bottom, In2)이 서로 직교**.
- 기존 PW3 후보(0/90 + 45만)의 상위 규칙: **어느 각을 쓰느냐가 아니라 층마다
  주방향을 정한다**.

### D10. 전원 플레인이 있으면 배선 폭을 하나로 통일한다 [배선]
- 근거: video는 +5V/GND가 플레인 → 배선 7932개 중 7855개가 0.2mm 단일 폭.
  interf_u는 플레인 없음 → 신호 0.432 / 전원 0.559로 2종 필요.
- **폭 규칙의 존재 이유는 전류가 아니라 "플레인이 없어서"다.** 층 수를 정하는
  순간 배선 폭 정책도 결정된다 (P4 "층수 사전 확인"과 직결).

### D11. 플레인 희생 순서: GND는 지키고 전원 플레인을 자른다 [배선]
- 근거: video In1(GND) 배선 639mm vs In2(+5V) 2713mm. 오버플로 신호를 전원
  플레인 층으로 뺐고 그라운드 층은 거의 통짜로 남겼다.
- 리턴패스가 끊기는 쪽이 GND이므로 순서가 이렇게 나온다.

### D12. 아날로그 전원은 인덕터로 갈라 별도 넷으로 관리 [회로+배치]
- 근거: video `/pal-ntsc.sch/VAF`(BT812 24핀)는 L4 22uH 뒤의 독립 넷,
  `/ESVIDEO-RVB/VAA`(BT253+BT473)는 L5 22uH 뒤 독립 넷. 각 넷 전용 디커플링
  (C2/C12/C13/C14/C62 등)이 따로 붙는다.
- 넷 이름을 분리하면 DRC/넷클래스로 기계 검증이 가능해진다.

### D13. 설정 점퍼는 그 설정을 읽는 IC 옆 [배치]
- 근거: video W2/W3(119.4·122.3, 125.2)이 U11에서 ~22mm, W1이 ~21mm.
  interf_u JP1(주소점퍼)–RR1(풀업)–U2(비교기)가 한 열로 21.7 / 11.4mm.
- 사용자가 손대는 부품이므로 **부품 밑이나 커넥터 뒤로 숨기지 않는다**.
  (단 video W1은 뒷면 — 이 원칙을 어긴 예.)

## 6. 한계·정직한 기록

1. **의도 기록이 없다.** 두 보드 모두 설계 노트가 없고, 위 해석은 좌표·넷·
   핀네임에서 역추론한 것이다. [추정] 표시가 붙은 항목은 기하만이 근거다.
2. **시대 보정 필요.** interf_u의 무-세라믹 디커플링, 1.4mm 비아, 0.43mm 배선은
   현대 규칙으로 그대로 쓰면 안 된다. D5·D10은 video 쪽 실측을 우선한다.
3. **표본 2장.** D2(등간격 정렬)는 SIMM·DIP 같은 스루홀 대형 패키지에서 뽑은
   것이라 0402 밀집 SMT 보드에도 그대로 적용되는지는 미검증.
4. **video의 아날로그 장거리 배선(280~356mm)은 규칙이 아니라 타협의 흔적**이다.
   D6(종단은 커넥터)이 그 타협을 견디게 해준 장치라는 게 이 보드의 교훈이지,
   "길게 끌어도 된다"가 교훈이 아니다.
5. **muxdata 시트가 PCB에서 3덩이로 쪼개진 이유**(U3~U5 뒷면 x=168.8, U6 앞면
   x=197.7, U22 x=304.9)는 완전히 설명하지 못했다. 앞면 공간 부족과 SIMM
   양끝 접속이 원인으로 보이나 [추정].
6. **U22 XC4003-VQ100(+5V 11핀)에 20mm 안 디커플링이 사실상 없다**(C11이 15mm,
   그나마 U10 것). 74LS245 4개도 디커플링이 없다. video 안에서도 D5가 균일하게
   지켜지진 않았다.
