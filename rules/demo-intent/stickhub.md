### 전원 사슬 (실측 넷 추적)

```
J1.pin1 (호스트 VBUS)
  └─ Net-(J1-Pin_1) [0.6 mm, Ø0.6/0.4 비아 1개]
      └─ JP1 (솔더브리지 2패드 1.5×1.5) ── 끊으면 외부 5V 입력점이 됨
          └─ VIN [0.6 mm] ─┬─ D24 (5V TVS)
                            ├─ C21 (0.1 µF/100 V, 2012)
                            └─ U2.1/2/3 = VDD·ON·D 전부 VIN에 묶임
                                └─ U2.5 (S, 소스) = +5V ─┬─ C22 22 µF (스위치 출력캡, U2.5에서 1.10 mm)
                                                          ├─ 22 µF ×14 (= README의 "308 µF")
                                                          ├─ C14~C20 0.1 µF/100 V ×7 (포트별)
                                                          ├─ D25 (5V TVS)
                                                          ├─ U1.8 VCC5 (+C1 1 µF)
                                                          └─ J2~J8 pin1 ×7
```

- U2 = **Renesas/Dialog SLG5NT1487V** (7.8 mΩ / 5 A 로드스위치, 방전 기능, TDFN-8 1.5×2 mm).
  ON 핀이 VDD·VIN과 같이 묶여 있어 **상시 ON**이고, CAP 핀(7번)의 C28 15 nF가
  슬루레이트를 결정 → 이 설계에서 U2는 스위치가 아니라 **인러시 제한기**로 쓰였다.
  README의 "short circuit protection"은 이 IC의 전류제한 특성에 기댄 것으로 보인다 `[추정]`.
- 풋프린트 `TDFN-8_..._Fused-Lead`는 패드가 1,2,3,5,7,8 만 존재 —
  3번 패드가 핀3+4(드레인), 5번 패드가 핀5+6(소스)을 덮는 **융합 리드**(대전류용).

### 클럭 (중요)

Y1 = 12 MHz, 50 ppm, **로드 16–20 pF**, 4-SMD 2.5×2 mm.
보드 전체에 `/XI`·`/XO`에 걸린 커패시터가 **하나도 없다**.
XR22417 데이터시트 확인 결과 **로드 커패시터와 피드백 저항이 IC 내장**이며
"crystal은 정격 로드 16–20 pF" 요구 → 부품표의 Y1 값 문자열과 정확히 일치.
→ 로드캡 생략은 실수가 아니라 IC 사양을 반영한 의도적 설계.

### LED 구동 (2색 안티패럴렐)

D15~D21 = Kingbright APHB1608 (적/녹 듀얼). 패드 GA·GK·RA·RK 중
- **GA + RK** → `Net-(D15-1)` → 470 Ω → `/LEDn`
- **GK + RA** → `/LC` (U1 pin1 = LED_CTL)

즉 녹색과 적색이 **역병렬**로 물려 있고, 저항 1개로 두 색을 공유한다.
`LED_CTL`과 `LEDn` 사이의 전류 방향이 색을 결정 `[추정: 데이터시트로 색 할당 규칙 미확인]`.

## 3. 배선 실측

### 3.1 배선폭 정책 (넷별 실측 — 넷클래스는 1개뿐이므로 **수동 폭 지정**)

| 넷 계열 | 폭 (길이 비중 순) |
|---|---|
| USB 차동 14쌍 + 업스트림 | **0.15 mm 단일** (예외 없음) |
| `/LED1~7`, `/LC`, `/XI`, `/XO`, TEST/RST/VBUS_SENSE | **0.15 mm** |
| `+1V8` | 0.25 (15.2 mm) > 0.15 (2.7) > 0.3 (2.7) |
| `+3.3V` | 0.25 (31.9 mm) > 0.3 (10.1) > 0.2 (1.1) |
| `+5V` | **0.6 (50.9 mm)** > 0.4 (15.7) > 0.5 (10.2) > 0.3/0.2 |
| `VIN`, `Net-(J1-Pin_1)` | **0.6 mm 주력** |
| `GND` | 0.4 (79.6 mm) > 0.25 (60.2) > 0.15 (39.7) > 0.6 (8.8) |

→ **신호 0.15 / 내부전원 0.25~0.3 / 5V·VIN 0.4~0.6** 3단계.

### 3.2 차동쌍

- 폭 0.15 mm, **중심간 0.30 mm(= 에지 간격 0.15 mm)** — 넷클래스의 diff_pair 설정과 일치.
- 인트라페어 스큐(총 배선길이 차):

| 쌍 | D− 길이 | D+ 길이 | 스큐 | 사행(서펜틴)을 넣은 쪽 |
|---|---|---|---|---|
| `/D−` `/D+` (업스트림) | 18.56 | 18.67 | **0.11** | /D+ (세그먼트 89개 vs 21개) |
| `/U1D±` | 8.89 | 8.91 | **0.01** | — |
| `/U2D±` | 5.87 | 6.97 | **1.10** ← 유일한 예외 | 미보정 |
| `/U3D±` | 14.48 | 14.50 | **0.02** | /U3D− (85 vs 19) |
| `/U4D±` | 20.55 | 20.55 | **0.00** | /U4D+ (47 vs 19) |
| `/U5D±` | 9.87 | 9.84 | **0.03** | — |
| `/U6D±` | 15.41 | 15.42 | **0.01** | — |
| `/U7D±` | 12.41 | 12.31 | **0.10** | — |

  → KiCad `tuning_pattern` 제너레이터 객체는 파일에 **없다**. 짧은 쪽 넷에만
  세그먼트 수가 4~5배 많은 것(0.6 mm 미만 세그먼트가 38~79개, 특정 구역에 몰림)으로
  보아 **손으로 그린 사행**으로 길이를 맞췄다.
- 층 전환: 각 다운스트림 데이터 넷에 **비아 정확히 1개**(업스트림 `/D±`만 2개).
  즉 앞면 커넥터 ↔ 뒷면 QFP를 **한 번만** 넘는다.
- 모든 데이터 비아에서 **가장 가까운 GND 비아까지 0.69~1.72 mm**(중앙값 ≈1.2) —
  층 전환마다 리턴패스 스티칭 비아가 짝지어져 있다.
- 임피던스: 코어 1.51 mm 위 0.15 mm 마이크로스트립은 90 Ω 차동에 한참 못 미친다.
  **이 보드는 임피던스 제어를 하지 않은 것**으로 보인다 `[추정: 스택업 계산 근거,
  프로젝트에 임피던스 관련 커스텀 DRC 규칙 파일 없음]`. 2층·저가 취미 보드의 타협.

### 3.3 GND / 존

- F.Cu GND 존: bbox y 79.0~**108.5** (본체까지만). B.Cu GND 존: y 79.0~**120.5** (텅 포함).
  → **플러그 텅은 앞면에 동박 포어가 없고 뒷면에만 GND 면**이 깔린다.
  텅 앞면은 접점 핑거만 남기고(패드 타입 `connect`, 페이스트 없음),
  D+/D− 핑거 아래를 뒷면 GND가 받쳐주는 구조.
- 스티칭 GND 비아 **49개** (전체 비아 87개 중 56 %). 보드 유효면적 ≈610 mm² 기준
  대략 **12 mm²당 1개**, 가장자리(x≈142.3·157.3)와 IC 주변에 집중.
- 존 패드연결은 **전부 solid** (서멀릴리프 없음) — 전원·GND 임피던스를 우선.
- B.Cu에는 GND 위에 **우선순위 높은 국소 전원 포어**를 겹쳐 놓았다:
  +5V prio 3 (8.89 mm², C23~C27/C34~C37/D25 벌크 군집 아래),
  +5V prio 2 (4.28 mm², C29~C33 군집 아래),
  +1V8 prio 5 (0.91 mm², U1.25/28 + C4/C13 근처).
  → 2층에서 벌크 캡 군집을 **면으로 묶어 ESR·인덕턴스를 낮추는** 기법.

### 3.4 비아

- Ø0.5/드릴 0.3 = 81개 (신호·일반). Ø0.6/드릴 0.4 = **6개** — 전부 `+5V`(5개)와
  `Net-(J1-Pin_1)`(1개), 즉 **대전류 넷만 큰 비아**.
- 마이크로비아·블라인드/매입 비아 금지 설정 → 저가 2층 공정 전제.

### 3.5 회전각

QFP U1이 −135°이고, 그 주변 수동소자는 ±45/±135°가 지배적(C1·C3·C5~C11·C13,
R1~R6, Y1, U2, 벌크캡 열). 보드 가장자리 부품(커넥터, C14~C20, LED, C29~C33)은
0/±90/180°. → **IC의 대각 핀열을 따라가는 부품은 IC와 같은 45° 격자에,
가장자리에 정렬되는 부품은 직교 격자에** 둔다.

  JST 핀 이름 `5V/D+/D-/G`(B.Silk)↔포트 열.

### 배선

- **SH-21 (차동쌍은 폭=간격, 0.15/0.15로 전 구간 고정)**
  근거: 8쌍 전부 중심간 0.30 mm, 폭 0.15 mm. 넷클래스 diff_pair 값과 일치.
- **SH-22 (인트라페어 스큐는 짧은 쪽에 사행을 넣어 0.1 mm 이하로)**
  근거: 8쌍 중 7쌍이 스큐 ≤0.11 mm. 사행은 `/D+`, `/U3D−`, `/U4D+`에서
  세그먼트 수 4~5배로 확인. **예외 1건: `/U2D±` 1.10 mm** (가장 짧은 쌍, 미보정).
- **SH-23 (데이터 쌍의 층 전환은 쌍당 1회, 비아 2개를 나란히)**
  근거: 다운스트림 14넷 각 비아 1개. 쌍의 두 비아 간격 0.6~0.7 mm 수준으로 인접
  (예: `/U6D±` (143.66,98.15)·(143.71,98.84)).
- **SH-24 (층 전환 옆에 GND 스티칭 비아)**
  근거: 데이터 비아 16개 전부 최근접 GND 비아까지 **0.69~1.72 mm**.
- **SH-25 (배선폭 3단계: 신호 0.15 / 내부전원 0.25~0.3 / 메인 5V·입력 0.4~0.6)**
  근거: 3.1절 표. 넷클래스가 1개뿐이므로 **폭은 전부 수동 지정**했다.
- **SH-26 (대전류 넷만 큰 비아)**
  근거: Ø0.6/0.4 비아 6개가 전부 `+5V`(5) / `Net-(J1-Pin_1)`(1).
- **SH-27 (삽입되는 엣지 커넥터 면에는 포어를 깔지 않고, 반대면에만 레퍼런스 면)**
  근거: F.Cu GND 존은 y≤108.5(본체)까지, B.Cu GND 존은 y≤120.5(텅 포함).
- **SH-28 (2층에서는 GND 포어 위에 국소 전원 포어를 우선순위로 겹친다)**
  근거: B.Cu +5V prio 3(8.89 mm²)·prio 2(4.28 mm²), +1V8 prio 5(0.91 mm²).
  각각 벌크 캡 군집·레귤레이터 출력핀 위에 정확히 얹혀 있음.
- **SH-29 (존-패드 연결은 solid, 서멀릴리프 없음)**
  근거: 존 5개 전부 `padconn = FULL`. 전원·GND 임피던스를 납땜성보다 우선.
- **SH-30 (GND 스티칭 밀도 ≈10~12 mm²당 1개, 가장자리 우선)**
  근거: GND 비아 49개 / 유효면적 ≈610 mm². 좌우 가장자리 x≈142.3·157.3에 열을 이룸.
- **SH-31 (배선 각도는 0/90/45만, IC 대각열을 따르는 부품은 IC와 같은 45° 격자)**
  근거: 부품 회전각이 0/±45/±90/±135/180만 존재. U1 −135° 주변 수동소자가 ±45/±135.

| 항목 | 상태 |
|---|---|
| U1 45° 회전의 "의도" | `[추정]` — 결과(핀 그룹↔목적지 방향 일치)는 실측이지만 저자의 문서화된 근거는 없음 |
| 임피던스 미제어 판정 | `[추정]` — 스택업(1.51 mm 코어)과 0.15 mm 폭으로부터의 계산 근거. 프로젝트에 임피던스 DRC 규칙·스택업 제약(`dielectric_constraints no`)은 없음 |

| README "short circuit protection"의 실제 소자 | `[추정]` — 회로에 OCS 핀 연결이 없다. U2(SLG5NT1487V)의 전류제한에 기댄 것으로 보이나 데이터시트 원문 접근 실패(403/타임아웃) |
| LED 색 할당(녹=열거됨, 적=폴트 등) | `[추정]` — 역병렬 결선은 실측 확정, 색-상태 매핑은 XR22417 LED_CTL 동작 미확인 |
| H1 "Strap" Ø3 홀 용도 | `[추정]` — 텅 목 중앙이라 스트레인 릴리프로 보이나 근거 문서 없음 |

| C38 미실장 판정 | `dnp` 플래그는 없고 Description 필드가 "Not Populated". J1/H1/JP1/J9/LOGO도 같은 표기 → **BOM 제외 표기 관습**으로 해석 |
