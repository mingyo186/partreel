# 데모 심층 분석 통합 정제 (2026-08-10)

원천: 보드별 의도 분석 5건 — video_interfu.md(D1~13) / stickhub.md(SH1~31) /
royalblue_feather.md(RB1~12) / one_air_max.md(OAM1~27) / cm5_minima.md(40건).
정제 기준: **2개 이상 보드에서 독립적으로 관측**된 것만 '수렴'으로 승격,
단일 보드 관측은 원 보고서에 남긴다 (여기 요약 안 함).

## 메타 발견 — 배치 우선순위의 실체 (5보드 공통)
실보드의 우선순위는 "배선 짧게"가 아니다:
1. **기구/폼팩터/핀맵** (M.2 기구가 PCIe 55mm를 이김, Feather 핀배열 불가침,
   SRAM-FPGA 28넷도 기구에 양보)
2. **보호·종단·정합 소자의 '자리'** (신호가 280mm를 날아와도 종단은 커넥터 발치)
3. **제어선(다수·고임피던스) > 전원선(소수·저임피던스)** — 전원은 굵게 멀리
   보내면 되지만 신호 무리는 짧아야 (OAM-19, D3)
4. 그 다음이 결선 최소화.
→ 우리 P규칙과 정합: P6(기구) > P13(자리) > P8/P10(신호) > 나머지.

## 수렴 규칙 (복수 보드 일치 — 확정 후보)

### 배치
- **CV1. 디커플링**: 전원핀 1개당 1개, 100nF ≤2mm / 벌크 10µF ≤5mm.
  (SH1 전핀 1.4~1.9mm 예외0, CM5 R-DEC-01 역전0, D5 핀수=캡수, RB8)
  같은면(2층)/반대면(다층·고전) — 층수에 따름. **P13 수치 게이트화 근거.**
- **CV2. 보호소자(ESD/TVS)는 커넥터 쪽**: 데이터 ESD ≤4mm(커넥터:IC 거리비
  1:3+), 전원 TVS ≤6~10mm. 고속(≥480M)은 스터브 금지 — 배선이 소자 패드를
  '관통'(인라인). (SH4~6, RB9, CM5 R-ESD-01/02, OAM-9)
- **CV3. 크리스털 등급제**: 고속(MHz) 같은면·비아0·≤3mm / 저속(32k) ≤5mm·
  비아 허용. 로드캡 ≤1.5mm — 단 **IC 내장 캡이면 외부캡 없음이 정답**
  (SH10/11, RB6/7).
- **CV4. 벅컨버터 파워루프**: 입력캡–IC–인덕터–출력캡 5~7mm 안, SW 노드
  같은층·비아0·최소면적 (RB8, OAM-5/6, CM5 R-DEC-02).
- **CV5. 커넥터 정련 (P2 개정 근거)**: **수평 진입형만 가장자리 의무**,
  수직 진입형은 내부 허용. 변마다 기능 분리(전원/신호/조작). 동종 커넥터는
  같은 열·같은 회전. (CM5 R-PLC-01/02/03, OAM-14~16, D6)
- **CV6. 동종 부품 정렬**: 같은 MPN·같은 역할은 축/회전/등간격 정렬 — 버스
  IC는 한 줄 등피치(넷 길이 편차 최소화 부수효과) (D2, CM5 R-PLC-03,
  OAM-16). **P11 확장 근거.**
- **CV7. 안테나**: 키프아웃은 전층 rule area + 존 아웃라인 절단의 이중 보장,
  안테나 단은 외곽 플러시 또는 노치로 돌출, 큰 금속(배터리·홀) 투영 밖
  (RB1~3, OAM-1~3, CM5 R-MEC-03). 부품 메타 `antenna_face` 후보 (P6 형제).
- **CV8. 접지 분할**: 분할 시 1점 연결(페라이트)이 원칙이고 **그 연결 부품을
  두 존 경계선 위에 앉힌다** (OAM-11, CM5 아날로그 분리, D12 유사).

### 배선 (PW 확장 근거)
- **CV9. 차동쌍**: 폭=간격을 넷클래스로 규정하고 그대로 배선 (SH21 0.15/0.15,
  RB10 넷클래스 피치=실측 피치). 쌍내 스큐 ≤0.1~0.3mm (프로토콜별),
  층전환은 쌍당 1회, **전환 비아 ≤1~1.7mm에 GND 리턴 비아 짝**
  (SH23/24, CM5 R-VIA-02 40/40 중앙값 0.72mm).
- **CV10. GND는 트랙이 아니라 존+스티칭**: 스티칭 간격 중앙값 ≤2mm(다층)/
  ~12mm²당 1개(2층), 가장자리 열 우선 (SH27~30, CM5 R-GND-01/VIA-03, D11).
- **CV11. 각도 0/45/90 확정** (전 보드; 기타 ≤2%) + 층별 주방향 (top 수직/
  bottom 수평 — 2층·고전 D9, 다층은 쌍층에만 고속 R-STK-01).
- **CV12. 폭 3단계**: 신호 0.15 / 내부전원 0.25~0.3 / 5V·VBUS 0.4~0.6
  (SH25, PW1 보강 — Power 클래스에서 5V만 승급 필요). 비아 1종 통일
  (CM5 444개 전부 동일; 대전류만 예외 승급 SH26).

## 우리 것에 반영할 제안 (승인 대기)
1. **[설계 조언] usb_c_5v 블록에 USB ESD가 없다** — 분석한 현대 보드 전부
   (SH/RB/CM5) 데이터·VBUS ESD 보유. ESD 블록(또는 usb_c_5v v2) 신설 제안
   (부품: USBLC6-2 류 또는 개별 TVS — 부품 등록부터).
2. **P13 게이트화**: check_board에 CV1 수치 검사 (place role=decoupling인
   부품의 대상 핀 거리 ≤2mm/벌크 ≤5mm 기계 판정).
3. **P2 개정**: '커넥터=가장자리'를 '수평 진입형만 의무'로 정련 (CV5) +
   edge_face 메타에 진입 방향 구분.
4. **P11 확장**: 동종 부품(같은 pid·같은 role) 축·회전·등간격 정렬 (CV6).
5. **PW 보강**: 5V/VBUS 전용 클래스 0.5mm (CV12), USB_DIFF 클래스
   0.15/0.15 (CV9) — .kicad_pro 넷클래스 추가.
6. **place 어휘 확장**: role에 esd(near=커넥터, 인라인), xtal/loadcap,
   buck_loop 추가 — 블록 저자 선언용 (P13 확장).
7. 배선 게이트(배선 단계 진입 시): 차동 스큐·리턴 비아·스터브 검사를
   check_board에 추가.

## 한계
- 수치들은 표본 5~6장 기반 — 공정·층수에 따라 달라지는 값(간격·폭)은
  '기본값+근거'로 취급, 절대 규격 아님.
- 각 보고서의 단일 관측(예: QFP 45°, mid-mount 노치)은 여기 승격 안 함 —
  필요할 때 원 보고서 참조.
- CM5 분석이 지적한 데모 자체의 의심 결함(U602 BOM 오기 등)은 우리와 무관,
  기록만.
