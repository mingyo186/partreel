# 규칙집 운영 (거버넌스)

사용자 지시 (2026-08-10): "규칙들을 만들다가 한 번씩 니가 규칙을 정리 좀 해 —
비슷한 규칙들이 충돌 안 나게 정리해야 된다."

## 운영 원칙
- 규칙은 사용자와 실물(블록/보드)을 만들며 확정된 것만 적는다 — 원문 인용 유지.
- **정리 주기**: 규칙이 **~10개** 늘어날 때마다(2026-08-10 사용자 조정; 또는 새 규칙집이 생길 때) 정리
  패스를 돌린다 — ①중복 병합(대체된 규칙은 삭제 대신 "→ Rn으로 대체" 표기)
  ②충돌 검사·우선순위 명시 ③기계 강제 여부(어느 게이트가 잡는지) 갱신.
- 번호는 재부여하지 않는다 (코드 주석·커밋이 번호를 참조).

## 정리 이력
### 2026-08-10 1차 정리 (R16 + P7 시점)
- **R10 ↔ R12 중복**: R10의 "참조기호 다음에 값" 배치 부분은 R12(2행 좁은
  행간·왼쪽 정렬)로 대체 — R10은 **단위 표기**(5.1kΩ 등)만 남는다.
  (schematic-readability.md에 표기)
- **P2 ↔ P3 우선순위**: 디버그 커넥터는 '커넥터니까 가장자리(P2)'와
  'MCU 근처(P3)'가 겹친다 — **P3 우선** (사용자 확정: 중소기업 관례는 MCU
  근처). 가장자리까지 겸하면 더 좋음 (강제 아님). 삽입식(P6 edge_face
  보유) 커넥터만 P2가 강제.
- **R7 ↔ R1 영역**: 심볼 내부 글자(R7)와 일반 텍스트 겹침(R1)은 같은
  '글자 겹침' 족 — 판정만 다름 (R7=외곽선 침범 0.25mm, R1=상자 겹침).
  충돌 없음, 족 표기만.
- **회로도 R와 PCB P는 영역이 달라 상호 충돌 없음** (R12 회로도 ref/값
  2행 vs P5 후보 PCB REF Fab 레이어는 서로 다른 문서의 규칙).
- 검토 결과 삭제할 규칙 없음.
