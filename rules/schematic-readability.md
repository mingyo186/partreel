# 회로도 가독 규칙집 (§24/§25) — 기능: 배치/표기

사용자 확정 규칙 (2026-08-08, USB-C 블록 1차 검토):
"글자가 겹쳐져 사람이 읽기 어려우면 안 되고, 라인은 심볼이나 다른 라인과
겹쳐져선 안 돼. 전압은 몇 볼트인지 표기가 되어야 하고, 부품은 어떤 부품인지
알아볼 수 있게 해줘야 해. 값 같은 게 라인이랑 겹쳐서도 안 돼."

## R1. 텍스트 겹침 금지 [기계 강제: check_block 텍스트-텍스트 검사]
어떤 텍스트(참조기호·값·핀이름·라벨)도 다른 텍스트와 겹치지 않는다.

## R2. 배선 겹침 금지 [기계 강제: check_block 동축 중첩 검사]
배선은 다른 배선과 같은 선 위에 겹쳐 깔리지 않는다.
(십자 교차는 허용 — 관례상 정상. 겹침 = 같은 축에서 구간이 포개지는 것)

## R3. 배선-심볼 겹침 금지 [기계 강제: check_block 몸체 통과 검사]
배선은 심볼 몸체(그래픽 영역)를 통과하지 않는다. 핀 접점만 닿는다.

## R4. 전압 표기 [반기계: 전원 심볼 Value 표시 + 렌더 확인]
전원 레일에는 전압값(+5V, +3V3 등)이 보이게 표기한다.

## R5. 부품 식별 표기 [반기계: Value 필수 표시]
부품마다 사람이 알아볼 표기(값 또는 통칭: "5.1k", "USB-C" 등)를 보이게 둔다.

## R6. 텍스트-배선 겹침 금지 [기계 강제: check_block 텍스트-배선 검사]
값·참조기호 등 텍스트는 배선 위에 얹히지 않는다.

## 기존 확정 규칙 (§24에서 이관)
- 전원 위 / GND 아래 / 신호 좌→우 흐름.
- 계층 라벨은 네트당 1장, 다핀 네트는 실배선. T자 접합은 junction 필수.
- (핀 할당, §25) 특수 핀이 아니면 부품이 놓일 방향의 핀을 배정.
