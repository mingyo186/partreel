# 회로도 가독 규칙집 (§24/§25) — 기능: 배치/표기

사용자 확정 규칙 (2026-08-08, USB-C 블록 1차 검토):
"글자가 겹쳐져 사람이 읽기 어려우면 안 되고, 라인은 심볼이나 다른 라인과
겹쳐져선 안 돼. 전압은 몇 볼트인지 표기가 되어야 하고, 부품은 어떤 부품인지
알아볼 수 있게 해줘야 해. 값 같은 게 라인이랑 겹쳐서도 안 돼."

## R1. 텍스트 겹침 금지 [기계 강제: check_block 텍스트-텍스트 검사]
어떤 텍스트(참조기호·값·핀이름·라벨)도 다른 텍스트와 겹치지 않는다.

## R2. 배선 겹침 금지 [기계 강제: check_block 동축 중첩 검사]
배선은 다른 배선과 같은 선 위에 겹쳐 깔리지 않는다.
(십자 교차는 허용 — 관례상 정상. 겹침 = 같은 축에서 구간이 포개지는 것)

## R3. 배선-심볼 겹침 금지 [기계 강제: check_block 몸체 통과 검사]
배선은 심볼 몸체(그래픽 영역)를 통과하지 않는다. 핀 접점만 닿는다.

## R4. 전압 표기 [반기계: 전원 심볼 Value 표시 + 렌더 확인]
전원 레일에는 전압값(+5V, +3V3 등)이 보이게 표기한다.

## R5. 부품 식별 표기 [반기계: Value 필수 표시]
부품마다 사람이 알아볼 표기(값 또는 통칭: "5.1k", "USB-C" 등)를 보이게 둔다.

## R6. 텍스트-배선 겹침 금지 [기계 강제: check_block 텍스트-배선 검사]
값·참조기호 등 텍스트는 배선 위에 얹히지 않는다.

추가 확정 (2026-08-08, 2차 검토): "심볼 내에 있는 글자도 신경 써야지 —
심볼 외곽하고 글자가 겹쳐 있어. 왼쪽 저항은 옆 라인이랑 너무 가까워 보여
오해할 수도 있어. 라인끼리의 간격이 웬만하면 일정해야 가독성이 좋아.
리퍼런스 다음에 값이 있어야 해. 단위를 적어야지 — 5.1이라고만 적으면
알기 어려워, 5.1ohm이거나 옴 기호라도."

## R7. 심볼 내부 글자-외곽 겹침 금지 [기계 강제: 외곽선 4변 대 글자상자]
핀 이름 등 심볼 안 글자는 몸체 외곽선과 겹치지 않는다. (심볼 자체 결함이면
부품 차원에서 수리 — 파트릴 심볼은 우리가 생성하므로 카탈로그로 환원)

## R8. 배선-부품 여백 [기계 강제: 몸체 상자 + 1.27mm 여백]
배선은 부품 몸체에서 최소 1.27mm(핀 길이 1칸) 떨어진다. 붙어 보이면
연결로 오해된다. (자기 핀에 닿는 배선은 핀 길이만큼 자연 이격)

## R9. 배선 간격 균일 [기계 강제(최소): 평행 간격 ≥ 2.54mm / 균일은 관례]
평행 배선은 최소 2.54mm(1그리드) 간격, 차선은 가급적 등간격으로 배열.

## R10. 참조기호-값 인접 + 단위 표기 [반기계: 배치 관례 + 값 표기 검사]
참조기호 바로 다음(아래)에 값. 값에는 단위를 쓴다: "5.1kΩ", "100nF",
"5.1Ω" — 숫자만 쓰지 않는다.

추가 확정 (2026-08-09, 3차 검토 — LDO 블록): "캐패시터가 너무 위쪽에 붙었어,
아랫라인과 윗라인의 중간지점에 있는 게 보기 좋아. 값과 리퍼런스가 붙어 있으면
보기 어려워 — C1 10µF 이런 식으로. 깃발과 전압 심볼이 너무 붙어 있어 —
차라리 3번 핀 앞쪽에 깃발을 둬. 그라운드 라인이 너무 아래쪽에 있으면 불편해."

## R11. 분로 부품은 상하 라인의 중간 [기계 강제: 상하 배선 길이 대칭]
전원-GND 사이에 걸리는 부품(디커플링 캐패시터 등)은 윗라인과 아랫라인의
중간에 — 위아래 배선 길이 차이가 1그리드(2.54) 이내.

## R12. 참조기호와 값은 가로로 나란히·붙여서 [기계 강제: 같은 줄 + 간격 ≤ 2.54]
"C1 10µF"처럼 한 줄에, 참조기호 끝에서 값 시작까지 **0.6mm(한 칸 느낌)** —
멀면 짝이 안 보이고 겹치면 읽기 어렵다. IC도 예외 없음 (U1 HT7333 3.3V).
배치는 자동 정렬기(렌더 실측 폭 기반)가 계산한다.

## R13. GND 레일은 회로 하단에 밀착 [기계 강제: 최하단 부품에서 ≤ 3그리드]
그라운드 레일이 부품들에서 너무 멀면 시선이 끊긴다 — 최하단 부품 아래
1~3그리드(≤7.62mm) 안에 둔다.

## R14. 깃발은 생성 핀 바로 앞 [배치 관례]
공급원 깃발은 전압 심볼 옆이 아니라 **그 전압을 만드는 핀 직후**에 두고,
다른 심볼과 2.54 이상 이격한다.

## 기존 확정 규칙 (§24에서 이관)
- 전원 위 / GND 아래 / 신호 좌→우 흐름.
- 계층 라벨은 네트당 1장, 다핀 네트는 실배선. T자 접합은 junction 필수.
- (핀 할당, §25) 특수 핀이 아니면 부품이 놓일 방향의 핀을 배정.
