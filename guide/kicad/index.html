How to use PartReel files in KiCad

Downloaded files from PartReel? Here is how to add them to KiCad.

1. Symbol (.kicad_sym)

  1. KiCad → Preferences → Manage Symbol Libraries
  2. In the Global or Project tab click + → select the downloaded .kicad_sym file
  3. Place the symbol from the schematic editor

2. Footprint (.kicad_mod)

  1. Put the .kicad_mod file inside a folder named like MyLib.pretty (KiCad manages footprints per .pretty folder)
  2. Preferences → Manage Footprint Libraries → + → add that .pretty folder

3. 3D model (.step)

  1. Open the footprint in the footprint editor → Footprint Properties → 3D Models
  2. Point it at the downloaded .step file

The web preview uses .glb (display only); use .step in KiCad.

4. Browse PartReel inside KiCad (HTTP library)

KiCad 8+ can show the whole PartReel catalog in the symbol chooser as a live library:

  1. Download partreel.kicad_httplib and PartReel.kicad_sym
  2. Preferences → Manage Symbol Libraries → + → add PartReel.kicad_sym with nickname PartReel
  3. + again → add partreel.kicad_httplib
  4. Open the symbol chooser — PartReel_Live categories appear (first open syncs for a few minutes), each part carrying its datasheet, page and direct download URLs in its fields

Heads-up: two KiCad-side limits, honestly stated. ① HTTP libraries carry metadata only (spec, not a PartReel limit) — placing a part inserts a placeholder symbol whose PartReel field links to the real symbol/footprint/3D downloads. ② KiCad pre-fetches every part one-by-one when the chooser first opens, so this library serves PartReel's curated, self-generated set (~450 parts) rather than the full 21,000+ catalog — search the full catalog at partreel.com or via the MCP server.
